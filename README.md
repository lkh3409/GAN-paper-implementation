# GAN Paper Implementation

TG-WinG AI 트랙에서 GAN 논문 발표를 준비하며 GAN·DCGAN을 PyTorch로 구현하고 MNIST로 학습해 본 코드입니다.

- `gan.py` : GAN 구현
- `implementation-deep-learning/` : [tyami/implementation-deep-learning](https://github.com/tyami/implementation-deep-learning)을 참고해 실습한 노트북(`code/`)과 학습 결과 이미지(`result/`, `GAN_results/`)

데이터셋(MNIST)과 학습된 가중치(.pth)는 용량 때문에 제외했습니다.
